# revision_csf — analyses added in the first revision

Scripts and stored results for the analyses added to the paper in revision: the main-text Tables 7–9, the revised
main-text Fig. 5, and Sections S13–S18 of the supplement (Tables S14–S37, Figs. S27–S30). Equation, table and figure
numbers refer to the revised manuscript.

Every script runs from this folder with `python3 <script>` and writes CSV files to `results/`. The scripts read the
reference tables of `../data_dose_units/results/`, import the shared helpers of `../round2_checks/`, and call two
compiled kernels: `m1_noiseform_sde` (this folder, `make`) and `../m0_joint_scan/m0_joint_scan`.

Run times, where given, are approximate (8 cores).

## Order

```bash
make                                   # m1_noiseform_sde (the kernel of ../m0_joint_scan must be built as well)
python3 a1_general_expansion.py && python3 a2_exact_vs_expansion.py --mc
python3 b1_fpt_density.py              # before b2 and b3
python3 a3_noise_forms_full.py         # before a4 and b2 (they read a3_matched_segmented.csv)
```

The remaining scripts are independent of each other. `plot_revision_figures.py` and `make_supp_sections.py` need only
the stored CSV files.

## Not stored

- `figures/` (regenerated by the two plot scripts), as elsewhere in this repository.
- `results/b1_fpt_density_*.pkl` (15 MB of density tables, regenerated by `b1_fpt_density.py` in about a minute).
  `b2_family_comparison.py` and `b3_robustness.py` need them; their CSV output is stored.

## Requirements

As for the rest of the repository, and in addition `statsmodels` for the mixed model in `c1_hierarchical_slope.py`
(the script skips that step if the package is missing).
